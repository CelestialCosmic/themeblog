# **大模型压测指标全景图（5 大类 20+ 指标）**

## **① 吞吐类指标（Throughput）**

衡量“单位时间能处理多少 token / 请求”，是最核心指标之一。

- **Prefill Throughput（tokens/s）** 大 batch、长 prompt 时的吞吐（算力密集）
    
- **Decode Throughput（tokens/s）** 小 batch、逐 token 生成（访存密集）
    
- **Requests per second (RPS)** 每秒能处理多少请求
    
- **Effective Throughput** 吞吐 × 成功率（考虑失败/超时）
    

这些指标直接决定你的服务能不能“扛住流量”。

## **② 延迟类指标（Latency）**

衡量响应速度，尤其对在线服务至关重要。

- **TTFT（Time To First Token）** 用户最敏感的指标
    
- **TPOT（Time Per Output Token）** 每个 token 的生成速度
    
- **End-to-End Latency** 从请求到完整响应的总时间
    
- **P50 / P90 / P95 / P99 延迟** 高并发下的尾延迟（最重要）
    

延迟指标决定用户体验是否“卡顿”。

## **③ 资源利用率指标（Hardware Utilization）**

用于判断瓶颈在哪里。

- **MFU（Model FLOPs Utilization）** 实际 FLOPs / 峰值 FLOPs
    
- **GPU SM 利用率** Tensor Core 是否吃满
    
- **Memory Bandwidth 利用率** decode 阶段常常是访存瓶颈
    
- **显存占用（VRAM Usage）** 模型 + KV Cache + batch 的占用情况
    
- **PCIe / NVLink 带宽利用率** 多卡推理时非常关键
    
- **CPU 利用率** tokenizer、调度、网络 IO
    

这些指标决定你是否“吃满硬件”。

## **④ 并发与稳定性指标（Concurrency & Stability）**

用于评估服务在真实流量下的表现。

- **最大并发连接数**
    
- **最大可承载 batch size**
    
- **队列长度（Queue Length）**
    
- **排队延迟（Queue Delay）**
    
- **错误率（Error Rate）**
    
    - 超时
        
    - OOM
        
    - 429（限流）
        
- **长时间运行稳定性（24h soak test）**
    

这些指标决定你的服务是否能“稳定跑一天”。

## **⑤ 质量与一致性指标（Quality & Determinism）**

性能之外的“正确性”指标。

- **输出一致性（Determinism）** 相同输入是否得到相同输出（尤其在多 GPU）
    
- **输出质量（BLEU / Rouge / GPTScore）** 性能优化后是否影响质量
    
- **漂移检测（Drift Detection）** 模型更新后输出是否异常

## 拉取镜像
```sh
docker pull
docker save {docker 的 ID}> out.tar

```
docker 镜像根据系统不同，大小也不一，一般来说 windows 的 docker 大小是 linux 的两倍

## 更新 cuda
现代模型部署至少需要 cuda 12.4，在 nvidia 官网可以找到更新，建议下载 .run，省事，无需重启

rpm 方式则需要确保 yum 源可用
```sh
wget 包
rpm -i cuda-repo-kylin10-12-4-local-12.4.0_550.54.14-1.x86_64.rpm
dnf/yum clean all
rpm -qa | grep cuda || yum localinstall 包
```

> yum 源使用 python2，且链接了 python，如果需要用 python3，记得切换

```sh
ln -s 要链接的地方 链接到的地方
```

yum python 版本不对的话，报错现象就是 keyboard interrupt
## 导入 docker
有 `docker import` 和 `docker load` 两种方式，用别人做好的镜像用 load，自己的两种都可以
```sh
docker import vllm < vllm.tar
docker tag <id> <org>:<name>
```
这种方式会导入镜像，但不使用镜像内的信息

```sh
docker load < vllm.tar
```
这种方式也会导入镜像，并且会自动导入镜像内的信息

## 拉起 docker
### ollama
```sh
docker run -d
--gpus=all
-v /var/models:/data
 -p 11434:11434
 --name ollama
 ollama/ollama
```

从上到下依次是：
--gpus=all：使用所有 gpu，
-v /var/models:/data：映射主机 /var/models 到 /data
-p 11434:11434：映射 docker 11434 端口到主机 11434 端口
--name ollama：docker 名
ollama/ollama docker 镜像名

### vllm
不需要在 docker 内操作
```sh
docker run -d
--runtime nvidia
--ipc=host
--gpus all
-v /var/models:/data
--p 8000:8000
--name vllm
vllm/vllm-openai:v0.8.5
--served-model-name 32b
--model /data/32b
--dtype bfloat16
--max-model-len 8192
--gpu-memory-utilization 0.95
```
### xinference
```sh
docker run
-p 9998:9997
-v /var/models:/data
--gpus all
xprobe/xinference:latest
xinference-local
-H 0.0.0.0
--log-level debug
```

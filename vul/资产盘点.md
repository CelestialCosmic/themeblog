L1： 域名层（入口外壳） 主域 / 子域 历史域名 第三方代维 / 代运营域名 云厂商 / SaaS 默认域名 
L2： IP / 端口层（网络映射） CDN 前 CDN 后真实源站 云 SLB / Nginx / 网关 
L3： 站点 / 虚拟主机层（一个端口 ≠ 一个业务） 同 IP + 端口下的多站点 不同 Host Header 路由 不同 ServerName 
L4： 路径 / 目录层（你已经意识到的难点） /portal /admin /app /xxx/login 前端路由型 SPA 反向代理子路径 
L5： 真实业务逻辑层（最容易漏） API 子系统 对外暴露但无 UI 的业务 第三方跳转 / iframe / OAuth 供应商平台代理访问
